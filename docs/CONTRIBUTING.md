# Contributing

Thank you for your interest in contributing to CFX Developer Tools.

The full, canonical contribution guide is [CONTRIBUTING.md in the repository root](https://github.com/TMHSDigital/CFX-Developer-Tools/blob/main/CONTRIBUTING.md): local setup, how to add skills, rules, snippets and templates, the checks CI runs, and the pull request process. This page only summarizes the parts every contributor needs; if anything here disagrees with the root guide, the root guide wins.

## Before you open a pull request

- **Sign off every commit (DCO).** Each commit needs a `Signed-off-by:` trailer matching the commit author, added with `git commit -s`. The GitHub DCO App blocks pull requests without it. By contributing you certify the Developer Certificate of Origin 1.1 and grant the inbound license described in the root guide (the project is published under CC-BY-NC-ND-4.0).
- **Use conventional commits** (`feat:`, `fix:`, `docs:`, `chore:` ...). `feat`, `fix`, `perf` and breaking changes trigger a release after CI passes.
- **Run the MCP server tests** when you touch `mcp-server/`: `cd mcp-server && pip install -r requirements-dev.txt && python -m pytest`.
- **No em or en dashes, no hardcoded credentials, no `lua54` directive** in manifests. CI enforces all three.

## Data files

- The native databases (`mcp-server/data/natives_*.json`) are generated by the weekly `update-natives.yml` workflow from `runtime.fivem.net/doc/`. Do not edit them by hand; change `.github/scripts/transform_natives.py` instead.
- `mcp-server/data/events.json` entries need `name`, `side` (client, server or shared), `framework`, `game` (gta5, rdr3 or shared), plus `description` and `params`. CI rejects entries missing `name`, `side`, `framework` or `game`.

## Reporting issues and ideas

Open a GitHub issue with a clear description, steps to reproduce (for bugs), expected versus actual behavior, and your environment (OS, Cursor or MCP client version, Python version).

Documentation changes auto-deploy to the [docs site](https://tmhsdigital.github.io/CFX-Developer-Tools/) when merged to `main`.
